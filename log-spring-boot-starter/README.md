# Log Spring Boot Starter

A lightweight Spring Boot starter demonstrating **Dependency Injection for SLF4J `Logger`** via Spring's `InjectionPoint` and a functional mixin interface (`LoggerProvider`) for execution-time logging.

> [!IMPORTANT]
> **Educational & Presentation Purpose Only (Not for Production)**
>
> This module is designed as a conceptual showcase of Spring Framework internals (`InjectionPoint`, `SCOPE_PROTOTYPE` beans) and modern Java idioms (interface `default` methods, functional wrappers, and seamless compatibility with Java `record` services).
>
> **Why it is not recommended for enterprise production:**
> - **Constructor Pollution**: Injecting `Logger` as a constructor dependency mixes cross-cutting infrastructure concerns with business collaborators and forces unit tests to pass mock loggers.
> - **Caller Location Masking**: Logging inside `LoggerProvider` default methods reports `LoggerProvider` as the caller method/line number (`%M:%L`) in log outputs rather than the actual business method.
> - **Better Production Alternatives**: In real-world production systems, prefer `private static final Logger` (or `@Slf4j`) combined with **Spring AOP**, **Micrometer `@Observed` / `@Timed`**, **OpenTelemetry**, and **MDC correlation filters**.

---

## Features

1. **Prototype `Logger` Bean Injection (`LogStarterAutoConfiguration`)**
   - Automatically registers a `@Scope(ConfigurableBeanFactory.SCOPE_PROTOTYPE)` bean of type `org.slf4j.Logger`.
   - Inspects `InjectionPoint#getMember` to resolve the declaring class dynamically and delegates logger creation to `LoggerFactory.getLogger(Class<?>)`.

2. **`LoggerProvider` Functional Mixin**
   - Exposes `Logger logger()` — designed to match the implicit accessor generated by Java `record` components without extra boilerplate.
   - Provides `executeAndLog(String message, Supplier<R> supplier)` and `executeAndLog(String message, Runnable runnable)` default methods that log entry (`[→]`), measure elapsed duration using monotonic `System.nanoTime()`, and log completion (`[←]`).

## Usage Example

### With Java `record` Service

Because `LoggerProvider` defines `Logger logger()`, a Java `record` with a `Logger logger` component implements the contract automatically:

```java
package com.example.demo;

import com.pavelshapel.starter.boot.spring.log.LoggerProvider;
import org.slf4j.Logger;
import org.springframework.stereotype.Service;

@Service
public record PaymentService(Logger logger) implements LoggerProvider {

  public String processPayment(String orderId) {
    return executeAndLog(
        "Processing payment for order " + orderId,
        () -> {
          // Business logic
          return "SUCCESS";
        });
  }
}
```

### Sample Console Output

```text
INFO com.example.demo.PaymentService -- [→] Processing payment for order ORD-101...
INFO com.example.demo.PaymentService -- [←] completed in [12] ms. Processing payment for order ORD-101
```
